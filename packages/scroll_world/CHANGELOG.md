## 0.1.0

- Initial Android, iOS, and web MVP.
- Added declarative responsive scenes and connectors.
- Added pure timeline math, bounded playback pooling, and coalesced seeking.
- Added poster-first failure handling, reduced motion, keyboard navigation, and semantics.
- Added custom overlay and video-driver extension points.
- Added the procedural stylized 3D “Kenya in Motion” demonstration and its
  reproducible Blender 5.2 LTS render pipeline.
- Added Blob-backed web media, animation-frame smoothing, adjacent-segment
  preparation, and optional first-gesture video priming.
- Added scene actions, linger pacing, `ScrollWorldController`, and an
  interruptible reverse-replay experience with reduced-motion fallback.
- Added a native HTML video surface on web that completes seeks only after a
  compositor frame, uses low-latency keyframe seeking, and corrects imprecise
  final positions for conventionally GOP-encoded footage.
