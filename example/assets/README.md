# Demo media

These MP4 and WebP files are original, deterministic renders generated by
`tools/blender/generate_kenya_world.py` with seed `254`. The world uses only
procedural Blender primitives and materials; it contains no third-party models,
textures, fonts, logos, or audio.

- `*-landscape.mp4`: 960×540 at 24 fps
- `*-portrait.mp4`: 540×960 at 24 fps
- `posters/*.webp`: focal frames used before video and for reduced motion

Regenerate and validate the complete set from the repository root:

```powershell
.\tools\render_3d_media.ps1 -Mode render
```

Do not edit connector endpoints independently. The renderer deliberately shares
the final frame of each scene with the first frame of its connector, and the
connector’s final frame with the following scene.
